# Análisis Exploratorio de Datos: Dataset de Cereales

Proyecto de introducción a Machine Learning enfocado en la exploración inicial de un dataset, identificación de tipos de variables y planteamiento de posibles problemas de ML.

## 🎯 Objetivo

Familiarizarme con los conceptos básicos de Machine Learning mediante la exploración de un dataset real, identificando variables, proponiendo una variable objetivo y planteando ejemplos de problemas supervisados y no supervisados.

## 📊 Sobre el dataset

Dataset de cereales con información nutricional (calorías, azúcar, fibra, proteína, etc.) y calificación (rating) de distintas marcas de cereal.

## 🔍 Contenido del análisis

- Exploración inicial de los datos (`df.head()`, `df.shape`, `df.info()`)
- Identificación de variables categóricas y numéricas
- Propuesta de variable objetivo (`rating`) con justificación
- Ejemplos de problemas de ML supervisado y no supervisado aplicados al dataset
- Visualización: relación entre contenido de azúcar y calificación del cereal

## 🛠️ Herramientas

- Python
- matplotlib

## 📈 Hallazgo principal

Se observa una relación negativa moderada entre el contenido de azúcar y el rating: los cereales con más azúcar tienden a tener calificaciones más bajas, aunque no es el único factor que influye.
