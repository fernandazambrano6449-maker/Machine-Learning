# Exploración de Distribuciones y Limpieza de Datos - Seguros Médicos

Este proyecto lo hice para practicar conceptos de probabilidad y estadística usando un dataset real de costos médicos de seguros.

## ¿Qué hice?

- Cargué el dataset de seguros médicos (Medical Cost Personal Dataset)
- Revisé si había datos faltantes o filas duplicadas (encontré 1 duplicado y lo eliminé)
- Analicé la distribución de la variable charges (costo médico) y la comparé contra una distribución normal
- Comparé los costos médicos entre distintos grupos (fumadores vs no fumadores, hombres vs mujeres, por región)
- Apliqué una transformación logarítmica para ver si mejoraba el ajuste a una distribución normal
